# Validation Plan

1. **Measurement reliability:** inter-coder agreement for inclusion, case type, question identity, cost components, and compression evidence.
2. **Construct validation:** compare description-length QC with knowledge-graph reorganisation and supplementary expert ratings.
3. **H1:** test whether tail-conditional DC is nondecreasing with QC using isotonic regression and bootstrap intervals.
4. **H2:** compare held-out prediction from DC+QC against either coordinate alone.
5. **H3:** test enrichment of independently labelled field-changing discoveries on the nondominated frontier.
6. **H4:** multiverse and sensitivity analysis across coding, weights, and normalisations.
7. **H5:** time-respecting dependency analysis for enabling discoveries.
8. Report genuine falsification conditions: poor reliability, unstable frontiers, no held-out gain, or reversal of scarcity results.
